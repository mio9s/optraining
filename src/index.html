① レンズデータ (光は左 → 右へ進みます)

曲率半径: 曲率中心が右側なら正・左側なら負、平面は inf。厚み: 次の面までの距離。材質: その面の右側の媒質。

物体・スクリーン
波長: (自然光・無偏光)

② 断面図 (子午面 y-z)

ホイールで拡大縮小、ドラッグで移動。視野 0 / 70 / 100 % から各 7 本。× は遮蔽された位置。

③ 結像

使い方

  1. ① レンズデータで光学系を入力します。1 行 = 1 面。先頭が物体面、末尾がスクリーンです。「＋」で面を挿入、「✕」で削除、「↑↓」で並べ替え。
  2. 曲率半径は inf で平面。材質は「その面の右側」の媒質です(レンズの最後の面は通常「空気」)。カスタムでは nd とアッベ数 νd を入力します。
  3. アイリス(絞り)は独立した行として好きな位置に置けます。直径を小さくすると光束が絞られます。
  4. 入力が不正なセルは赤枠になり、計算は直前の正しい状態のまま続きます。
  5. ② 断面図は入力に合わせて自動更新されます。青 450 nm / 緑 520 nm / 赤 620 nm。
  6. ③ 結像: パターンを選ぶか画像を読み込み、「結像を計算」を押します。PSF(回折または幾何)を畳み込んだ像、ゴースト、散乱光、ラマン光を合成表示します。
  7. 右側のタブで色収差、ゼルニケ係数、散乱の各公式、散乱の設定を確認・変更できます。
  8. 編集内容はこのブラウザに自動保存され、次回開いたときに復元されます。「保存」で JSON ファイルに書き出し、「読込…」で戻せます。

単位: 長さ mm、波長 µm(表示は nm)。座標: 光軸 +z(右)、+y(上)。曲率半径は曲率中心が +z 側で正。
