# optraining — 光線追跡・結像・収差シミュレーター

球面レンズ系の 3 次元光線追跡、PSF を反映した結像画像、色収差・ゼルニケ解析、フレネル反射(ゴースト)・散乱(レイリー/ミー/表面/霧)・ラマン散乱を扱う、**オフラインで動く単一 HTML** のシミュレーターです。

## 使い方

**Web 版: https://mio9s.github.io/optraining/** (インストール不要、誰でもアクセス可)

または `dist/optraining.html` をダウンロードしてブラウザ(Chrome / Edge / Firefox / Safari の最新版)で開くだけです。インストールやネット接続は不要です。

1. **① レンズデータ**: 1 行 = 1 面。先頭が物体面、末尾がスクリーン。「＋」で挿入、「✕」で削除、「↑↓」で並べ替え。
   - 曲率半径: 曲率中心が右(+z)側なら正、平面は `inf`。厚み: 次の面までの距離。材質: その面の右側の媒質。
   - 材質はプリセットガラス(N-BK7, N-SF5, N-SF11, N-SK16, N-F2, N-LAK9, N-BAF10, 石英)か、カスタム(nd・νd)。
   - アイリス(絞り)は独立した行として任意の位置に置けます。
   - 不正な入力は赤枠で示され、計算は直前の正しい状態で続きます。
2. **② 断面図**: 入力に合わせて自動更新。ホイールで拡大、ドラッグで移動、「レンズ付近」「全体表示」。
3. **③ 結像**: パターンを選ぶか画像ファイルを読み込み、「結像を計算」。直接光・ゴースト・散乱光・ラマン光を切り替えて表示。
4. 右のタブ: 色収差 / ゼルニケ(視野・波長別) / 散乱の公式(各式を単独で計算・グラフ表示) / 設定(散乱係数、霧、光線数など)。

上部の「サンプル系」から、アクロマート(既定)、BK7 平凸単レンズ(f = 100 mm)、無分散ガラス単レンズを読み込めます。

## 外観(界面の見え方)タブ

レンズ・オイル層・接着剤・鏡筒などの部品を、色々な角度から見た写実的な画像として描き、**部品どうしの界面の反射が境界として見えるか**を確かめます。

- **部品**: 結像タブのレンズデータから、コバ・段差付きの立体を自動生成します。部品の断面は「断面を描いて追加」(直線・円弧・ベジェ・スプライン・非球面、グリッド/スナップ、元に戻す、下絵、数値編集、レンズのひな形)か、SVG / DXF / CSV の取り込みでも作れます。断面は光軸まわりに回転させて立体にします(回転対称)。
- **材質・コート**: ガラス、nd・νd 指定の媒質(オイル・樹脂)、不透明材(黒・アルマイト・アルミ・白・完全吸収体)。面ごとに単層・多層の薄膜コート(干渉色を含む)を指定できます。
- **描画**: 非逐次のスペクトル光線追跡(フレネル・薄膜の反射と透過を分岐追跡)。照明は環境プリセット(明るい室内、暗室+スポット、白、格子、黒)と、点光源・面光源(蛍光灯)。ドラッグで回転、角度一覧で並べて比較。
- **数値**: 界面ごとの反射率(角度・波長)、画像の明るさに対する各面の反射の寄与、線に沿った明るさ断面と境界のコントラスト判定(閾値 既定 2 %、ノイズを考慮)、**内部界面の見え方マップ**(内部界面の反射だけを消した画像との差を画素ごとに表示)。

### 例: 流体充填可変焦点レンズ(特許第 6831374 号の実施形態を基にした推定構成)

`examples/patent-6831374-fluid-lens.json` を「読込…」で開くと、結像タブ(格子パターン)と外観タブ(部品名・バリア層・フロントリム付き)の両方が設定された状態になります。サンプル系の一覧からも選べます(外観は自動生成)。
特許に記載のない値(曲率、流体の厚さ、後部レンズの材質 = PC と仮定、各材料のアッベ数、円形 Φ40 で近似)は推定です。

## 物理モデルと規約

| 項目 | 内容 |
|---|---|
| 座標・単位 | 光軸 +z(右)、+y(上)。長さ mm、波長 µm。曲率半径は曲率中心が +z 側で正 |
| 光源 | 自然光(無偏光)、0.45 / 0.52 / 0.62 µm(配列で拡張可能) |
| 屈折 | 3 次元ベクトル形スネルの法則。全反射・開口外・球と交わらない光線は遮蔽として除外 |
| 分散 | プリセット: Sellmeier 式。カスタム: 2 項コーシー式 n = A + B/λ²(nd・νd を厳密に再現) |
| 開口絞り | 近軸マージナル光線高 / 開口半径 が最大の面。光線は絞り面上の格子点をニュートン法で狙う |
| 色収差 | 縦: 近軸像位置の差。倍率: 最大物体高の実主光線のスクリーン上像高の差 |
| 波面 | OPD = OPL(光線, 参照球まで) − OPL(主光線)。参照球: 中心 = 主光線のスクリーン交点、射出瞳基準 |
| ゼルニケ | Noll 番号、RMS = 1 規格化、37 項の最小二乗フィット。補正不足の球面収差で Z11 < 0 |
| PSF | 波面から FFT(回折)。収差が大きく位相サンプリングが足りない場合は幾何スポット × 回折限界 PSF |
| 結像 | 物体を主光線で写像(歪曲・倍率色収差を含む)し、視野パッチごとの PSF で畳み込み。照度は ケラレ × cos⁴θ × 面積比 × フレネル透過 × NA² |
| 反射 | 無偏光フレネル。2 回反射ゴーストを全面ペアについて追跡 |
| 散乱 | ガラス内部(レイリー型 λ⁻⁴)、表面(TIS、Lambert 分布)、空間の霧(ミー、BHMIE)。モンテカルロ(強制衝突法)でエネルギー収支も表示 |
| ラマン | 1/λ_s = 1/λ − Δν、反ストークス比 = (λ_s/λ_as)⁴·exp(−hcΔν/kT)。ストークス光はオレンジ、反ストークス光は紫で表示 |
| 外観の形状 | 断面を弦誤差 0.1 µm で円錐台に分割し、交点は 2 次方程式で厳密に、法線は元の曲線から補間 |
| 外観の色 | 400〜700 nm を 16 帯に分けた波長で追跡し、CIE 1931 等色関数で sRGB へ(等エネルギー白 = 中性灰) |
| 薄膜 | 特性行列法(s・p、多層、全反射・エバネッセント結合を含む)。厚い層(接着剤 25 µm など)は部品として扱い、白色光では非干渉 |

詳細は `docs/superpowers/specs/2026-11-04-optical-simulator-design.md` §6.1。

## 検証

`npm test` で 100 件以上のテストを実行します。光線追跡は次の独立な方法で確認しています。

- 第三者実装 **rayoptics 0.9.10** との比較(3 系 × 3 波長、子午・スキュー光線 36 本): スクリーン交点の差 < 1e-13 mm、光路長の差 < 1e-12 mm(`test/fixtures/rayoptics-reference.json`、再生成手順は `scripts/verify/README.md`)
- 可逆性(逆追跡で物体点に戻る)、スキュー不変量 n(xM − yL) の保存、フェルマーの原理(光路長の停留性)
- 解析解: レンズメーカー式(BK7 平凸 f = 100 mm)、薄肉レンズの結像式、平行平板の横ずれ、球レンズの焦点距離
- ガラス: SCHOTT カタログの nd・νd と照合
- ミー散乱: miepython 3.3.1 の参照値と 1e-4 で一致、S11 の積分 = Qsca、x → 0 でレイリーに一致
- PSF: 回折限界のエアリー第 1 暗環 1.22 λN、回折 PSF の重心 = 実光線スポットの重心(コマ)

## 開発

```sh
npm install
npm test          # 単体テスト(node:test)
npm run build     # dist/optraining.html を生成
npm run import-glass  # ガラスデータを再取り込み(通常不要)
```

構成: `src/core/`(DOM に依存しない物理計算)、`src/ui/`(画面)、`scripts/build.mjs`(esbuild でバンドルし 1 つの HTML にインライン化。重い計算は Web Worker)。
