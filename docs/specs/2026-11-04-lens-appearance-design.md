# レンズ外観シミュレーション(界面の見え方の検証)設計書

日付: 2026-11-04 / 状態: 実装済み / 親設計: `2026-11-04-optical-simulator-design.md`

## 1. 目的
複数のレンズ(および接着剤・オイル層・鏡筒などの部品)を色々な角度から見たときに、部品どうしの**界面の反射が境界として目に見えるか**を検証する。レンズ形状は球面に限らず、2 次元で描いた断面(取り込み・アプリ内描画)を光軸まわりに回転した立体として扱う。

## 2. ユーザー決定事項(Q&A の結果)
| 項目 | 決定 |
|---|---|
| 確認方法 | 外観画像(任意視点の光線追跡レンダリング)+ 数値 |
| 形状の取り込み | SVG・CSV・DXF の取り込み + アプリ内で描く(自由度の高いエディタ) |
| 描く単位 | 部品の**閉じた断面**(前面・コバ・後面・段差・面取りを含む輪郭)。回転体として立体化し、光線は面の順序に縛られない(非逐次) |
| 照明・背景 | プリセット環境 + 点光源・面光源の追加 |
| 界面の反射 | フレネル(無コート)+ 面ごとの単層・多層薄膜コート(干渉による色付き)。接着剤・オイルの薄い層も薄膜として扱える |
| シーン | 現在のレンズデータからコバ付きの部品を自動生成し、任意の部品を取り込み/描画した断面に置き換え・追加できる |
| 視点操作 | ドラッグで回転(操作中は粗く、止めると精細化)+ 指定角度の画像を並べた一覧を自動生成 |
| エディタの要素 | 直線・円弧、自由曲線(ベジェ・スプライン)、非球面の式、補助機能(グリッド・スナップ・寸法・元に戻す/やり直し・下絵) |
| 数値出力 | 界面ごとの反射率の角度・波長依存グラフ、画像上の線に沿った明るさ断面と境界コントラスト、識別閾値(既定 2 %、変更可)による「見える/見えにくい」判定 |

## 3. ゴール / ノンゴール
**ゴール**: 上表のすべて。既存の結像シミュレーター(逐次光線追跡)と同じ単一 HTML に「外観」画面として追加し、オフラインで動作させる。

**ノンゴール**
- 回転対称でない形状(自由曲面、偏心・傾き)。将来の拡張として、部品に位置オフセット(z)のみ持たせる
- 外観描画での回折、散乱、コースティクス(ガラスを通した光が拡散面に作る集光模様)
- 取り込んだ断面を既存の結像・収差解析(逐次)に使うこと(ユーザー選択により今回は外観専用)
- 3D モデル形式(STEP/STL など)の取り込み

**アンチゴール**: 見た目がそれらしいだけで反射率が物理的に誤っていること。反射率はフレネル式・薄膜の特性行列法で計算し、テストで理論値に固定する。

## 4. 形状モデル
- **断面(プロファイル)**: (r, z) 平面上の閉じた輪郭。r ≥ 0、光軸は r = 0、z は既存と同じく光の進む向き。セグメントの種類:
  - 直線、円弧(中心・半径・角度、または 3 点)、3 次ベジェ、スプライン(通過点指定の自然 3 次スプライン)、非球面(z = z₀ + c r² / (1 + √(1 − (1+k) c² r²)) + Σ A₂ᵢ r²ⁱ、r 範囲指定)
  - 光軸上(r = 0)に乗るセグメントは回転すると面にならないため、境界として扱わない
- **検証**: 閉じていること、自己交差しないこと、r ≥ 0、部品どうしが重ならないこと(接する面は可)。違反はエディタで赤表示し、描画は直前の有効な状態を保持する
- **内部表現**: 各セグメントを弦誤差 0.1 µm 以下の折れ線に分割し、各線分を回転した円錐台(円筒・円環を含む)の集合とする。交点は円錐台と光線の 2 次方程式で解析的に求め、**法線は元の曲線の厳密な法線を補間**する(反射像に多面体の角が出ないように)。(r, z) 空間のバウンディングボックス階層で高速化する
- **部品**: {名前, 断面, 材質, 面ごとのコート割り当て, z オフセット}。材質はガラス(プリセット/nd・νd)、空気、および不透明材質(黒つや消し、黒アルマイト、アルミ、白拡散)
- **自動生成**: レンズデータの「ガラス(または液体)で満たされた区間」ごとに、前後の球面とコバ(直径の円筒面、前後で直径が違えば段差の平面)からなる閉じた断面を作る。オイル層のように隣の部品と面を共有する場合は同じ曲線を共有させる。オプションで鏡筒(黒アルマイトの円筒)を付ける

## 5. 光学モデル(外観描画)
- **非逐次追跡**: 光線と全部品の境界の最も近い交点を求め、交点の手前側・向こう側の媒質を「その点がどの部品の内部にあるか」の判定で決める(接着面のような共有面は 1 回の界面として扱える)
- **界面**: 屈折率 n₁→n₂ の無偏光フレネル反射・透過。コートがあれば特性行列法(s・p 偏光別、多層、入射角・波長依存)で R・T を求め、平均する。全反射も扱う
- **分岐**: 反射と透過の両方を追う。浅い分岐(深さ 3 まで)は両方追跡し、それより深い分岐は R の確率で一方を選ぶ(ロシアンルーレット)。最大深さ 12
- **色**: スペクトル描画。各画素サンプルで 400〜700 nm の波長を層化抽出して追跡し、CIE 1931 等色関数で XYZ に積算、sRGB に変換する。これで分散による色づきと薄膜干渉色の両方が正しく出る。画面の更新ごとにサンプルを重ねて精細化(プログレッシブ)
- **照明**: 環境(背景)は方向の関数として与える。プリセット: 明るい室内(上方が明るいグラデーション + 窓)、暗室 + スポット光、白背景、格子背景(歪みの確認用)、黒背景。光源: 点光源(有限半径の球として見える)、面光源(矩形パネル、蛍光灯を想定)。位置・大きさ・強さを指定する
- **不透明材質**: 拡散(ランバート)+ 鏡面(金属・アルマイトは反射率を指定)。光源への直接照明は影の光線で求め、ガラスを通る影はフレネル透過率を掛ける近似(屈折による光の曲がりは無視)とする
- **カメラ**: 注視点の周りを回る(方位角・仰角・距離)透視投影、画角指定。ドラッグ中は 1/4 解像度、止めると全解像度で精細化

## 6. 数値出力
1. **反射率グラフ**: 選んだ界面について、入射角 0〜90° × 波長(400〜700 nm)の R(s・p・平均)。コートの有無を比較表示
2. **明るさ断面**: 描画画像上にユーザーが引いた線に沿って輝度 Y(CIE)を表示し、境界(局所的な最大/最小)と周囲の平均からウェーバーコントラスト C = (L_境界 − L_周囲) / L_周囲 を求める
3. **判定**: |C| ≥ 閾値(既定 2 %、変更可)なら「見える」、未満なら「見えにくい」。人の目の識別閾値は条件(広い一様面で約 1〜2 %、細い線ではより高い)により変わる簡易的な目安であることを画面に明記する
4. **界面ごとの寄与**: 現在の視点で各界面の反射が画像の明るさにどれだけ寄与しているか(その界面での反射を経た光の割合)を表で示す

## 7. 取り込み形式
| 形式 | 対応範囲 |
|---|---|
| SVG | `path`(M L H V C S Q T A Z、相対座標含む)、`line`・`polyline`・`polygon`・`rect`・`circle`・`ellipse`、`transform`。読み込み時に、単位(1 単位 = 何 mm)、光軸の位置と向き(どの直線を光軸とするか)を指定する |
| DXF | ASCII DXF の `LINE`・`ARC`・`CIRCLE`・`LWPOLYLINE`(bulge 付き円弧)・`POLYLINE/VERTEX`・`SPLINE`(B スプライン)。単位は `$INSUNITS` から読み、指定で上書き可 |
| CSV | 2 列の点列(列の意味 r,z / z,r を選択)。閉じた折れ線、または「なめらかにつなぐ(スプライン)」を選択 |

取り込んだ断面は描画エディタで開き、そのまま編集できる。複数の閉じた輪郭を含むファイルは、輪郭ごとに部品として取り込む。

## 8. 画面
- 上部に「結像」「外観」の切り替えタブを追加
- 外観画面: 左に部品リスト(自動生成/取り込み/描画、材質、コート)、中央に描画画像(ドラッグで回転、線を引いて断面)、右に数値(反射率グラフ・明るさ断面・判定・寄与表)と照明設定
- 断面エディタ: 部品の断面を開くダイアログ。ツール(選択・直線・円弧・ベジェ・スプライン・非球面)、グリッド/スナップ、寸法、元に戻す/やり直し、下絵画像、点・セグメントの数値編集表
- 角度一覧: 方位角・仰角の範囲と刻みを指定して、サムネイルを並べて生成(Worker で並列)
- 保存: 部品・照明・カメラをレンズデータと一緒に自動保存し、JSON の保存・読込に含める

## 9. 受け入れ基準
1. 無コート BK7 平板(厚さ 5 mm)を垂直に見たとき、一様な面光源の反射の明るさが、多重反射を含む理論値 R_total = 2R / (1 + R)(R = 4.2 %)に 2 % 以内で一致する
2. 屈折率・分散が等しい 2 部品の接合面は見えない(コントラスト < 0.1 %、判定「見えにくい」)
3. BK7 上の MgF₂ 単層 λ/4 膜(550 nm)で、垂直入射の反射率が理論値 ((n₀n_s − n₁²)/(n₀n_s + n₁²))² に一致し、反射色が紫がかる(青と赤が強い)
4. 反射率グラフで p 偏光がブリュースター角で 0 になる
5. 同じ平凸レンズを SVG・DXF・CSV・アプリ内描画・自動生成で作ったとき、形状差 < 1 µm、描画画像の差が小さい
6. 視点を回すと画像が変わり、指定角度の一覧が生成される
7. 前回の系(BK7 平凸 + シリコンオイル + 空気 + BK7 平板)で、各界面の反射率と見え方(判定)が表示される

## 10. 実装者判断(設計時点)
- 曲線は細かい円錐台に分割して解析的に交差させ、法線は元曲線から補間(高精度・高速・実装が簡潔)
- スペクトルはプログレッシブな層化サンプリング(分散と干渉色を同時に正しく扱える)
- 重い描画は複数の Web Worker で画面をタイル分割して並列化
- 外部ライブラリは追加しない(SVG パス・DXF・スプライン・薄膜計算は自前で実装し、テストで固定)
