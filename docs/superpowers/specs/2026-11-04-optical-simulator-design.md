# 光学シミュレーター (optraining) 設計書

日付: 2026-11-04 / 状態: ユーザー確認待ち

## 1. 目的と背景
Zemax 等を参考に、複数枚の球面レンズで構成される撮像系の光線追跡シミュレーターを、ブラウザで動く単一の HTML として作る。
有限距離にある広がりのある物体(パターン/画像)の結像を確認し、色収差・コマ収差などの収差を解析できるようにすることが最終目標。「結像試験」と「収差の理解・分析」が主目的で、設計の自動最適化ツールではない。

## 2. ゴール / ノンゴール / アンチゴール
**ゴール**
- 球面レンズ系の 3 次元光線追跡(スキュー光線含む)と、2 次元断面図の表示
- 物体パターンの結像画像(PSF 反映)
- 色収差(縦・倍率)の数値表示
- 波面収差のゼルニケ係数分解の表示
- 反射・散乱(下記 §6)を光線強度への反映と独立計算パネルの両方で提供

**ノンゴール(今回やらない)**
- 非球面・自由曲面、回折/ホログラム面
- 3 次元表示(将来追加可能な構造にはしておく)
- 設計の自動最適化、公差解析
- 光源の 4 波長目以降(ただし波長配列は拡張可能に実装)

**アンチゴール**
- 計算結果がもっともらしく見えるだけで、光学的に正しくないこと(スネルの法則、符号規約、波面基準の誤りなど)。見た目より物理的正しさを優先する。

## 3. 制約
- 成果物は単一 HTML ファイル。ライブラリは利用してよいが、CDN 参照ではなくコードとして HTML 内に埋め込み、オフラインで動作させる。
- 光学計算は最初から 3 次元。表示のみ 2 次元断面。
- 光源: 自然光(無偏光)、3 波長 0.45 / 0.52 / 0.62 µm。
- 単位は mm(波長のみ µm)。リポジトリ: https://github.com/mio9s/optraining(公開)。

## 4. ユーザー入力(ユーザー指定)
**レンズデータエディタ(Zemax 風の表)**: 1 行 = 1 面。行の追加・削除・並べ替えが可能。
列: 面種別(物体 / レンズ面 / アイリス / スクリーン)、曲率半径(∞ = 平面)、厚み(次面までの距離)、材質、直径(開口)。
- 材質: 屈折率 nd とアッベ数 Vd を最低限入力可能。プリセット(BK7、SF11、石英など)を選択でき、自由入力も残す。ガラスデータは公開ライブラリ/データベース(refractiveindex.info 等)を実装時に調査して取り込む。
- アイリスはレンズとは別の行として、任意位置に配置可能。
- スクリーンは最終面に配置し、サイズと画素数を指定できる。
- 物体: 有限距離。物体面までの距離とサイズを指定。パターンは内蔵図形(矢印、解像力チャート、格子等)と、ユーザーが読み込む画像ファイルの両方に対応。

## 5. 出力
- 2 次元断面図(子午面)。光線は 3 波長で色分け。
- スクリーン上の結像画像(物体パターンを PSF で畳み込み)。
- 色収差の数値表示: 縦色収差(軸上の焦点位置差)、倍率色収差(像高差)。
- 波面収差のゼルニケ係数一覧(球面収差、コマ、非点収差、像面湾曲、歪曲など)。
- 反射・散乱: 画像の明るさ/ゴースト/迷光への反映と、公式ごとの独立パネル(角度・波長を入力して散乱強度のグラフ)。

## 6. 物理モデルの方針
- **屈折・分散**: スネルの法則。nd と Vd から 3 波長の屈折率を求める(F, d, C 線の定義に基づく近似式。使用式は実装者が選び、設計書に明記)。
- **ゼルニケ**: 射出瞳上の波面収差(OPD)をゼルニケ多項式(Noll または ANSI 規約を明記)にフィットして係数を表示。同じ波面から PSF(フーリエ変換)を計算し、像へ畳み込む。
- **反射**: 各面でフレネル反射(無偏光平均)。2 回反射によるゴースト光線を追跡。
- **散乱**(3 箇所で発生させる): ガラス内部、レンズ表面(粗さ・汚れ)、空間(霧・粒子)。
  - レイリー散乱(波長の 4 乗に反比例)、ミー散乱(粒子径依存、前方/後方の非対称性)
  - 前方散乱 / 後方散乱の角度分布(Henyey-Greenstein 等の位相関数)
  - ラマン散乱: ラマンシフト(波数)から波長変化を計算し、ストークス光・反ストークス光を元の 3 波長とは別の色で表示。
- 各係数は妥当な既定値を持ち、ユーザーが変更できる。

### 6.1 実装で確定した規約(実装者判断)
- **分散式**: プリセットガラスは refractiveindex.info-database(CC0, commit `c5c2f188e848453def5970e347399d653df2ffc2`)の Sellmeier 係数 n² = 1 + Σ Bᵢλ²/(λ² − Cᵢ)。nd・vd 入力のモデルガラスは 2 項コーシー式 n(λ) = A + B/λ²、B = (nd−1)/vd ÷ (1/λF² − 1/λC²)、A = nd − B/λd²(nd, vd を厳密に再現)。
- **ゼルニケ**: Noll 番号付け、単位円上で RMS = 1 に規格化。θ は +x から +y へ、偶数 j が cos、奇数 j が sin。子午面 (y-z) の視野によるコマは Z7。
- **OPD**: OPD = OPL(光線, 参照球まで) − OPL(主光線)、単位 waves。参照球の中心は主光線とスクリーンの交点、半径は射出瞳(開口絞りの近軸像)上の主光線位置からの距離。この符号では補正不足の球面収差(正の単レンズ)で Z11 < 0。
- **開口絞り**: 近軸マージナル光線高 / 開口半径 が最大の面。光線は絞り面上の格子点を狙ってニュートン法で照準。
- **倍率色収差**: 最大物体高の実主光線のスクリーン上像高の差 y(最短波長) − y(最長波長)。

## 7. 実装者に任せること(作者の判断)
- 使用ライブラリ(FFT、グラフ描画、ガラスデータ等)の選定
- 分散式、ゼルニケの規約、位相関数の具体形
- UI の見た目とレイアウト
- 追跡する光線の本数と性能チューニング

## 8. 受け入れ基準(動作の目安)
- 既知の単レンズ(例: BK7 平凸)で、近軸焦点距離が理論値(レンズメーカー式)と一致する。
- 単レンズで球面収差と色収差が現れ、ゼルニケ係数と数値表示に出る。
- 屈折率を全波長同一にすると、色収差がゼロになる。
- アイリスを絞ると、断面図・結像画像の双方が変化する。
- 画像ファイルを読み込むと、倒立像がスクリーンに表示される。

## 9. 今後の拡張(ノンゴールだが構造は意識)
