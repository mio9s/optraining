# レンズ外観シミュレーション Implementation Plan

**Spec:** `docs/superpowers/specs/2026-11-04-lens-appearance-design.md`

**Architecture:** 物理・幾何は DOM 非依存の `src/appearance/` に置き `node:test` で検証。UI は `src/ui/appearance/`。描画は Worker プール(Blob URL)でタイル並列。既存の逐次系(`src/core/`)は変更しない(ガラス・ベクトル・フレネルを再利用)。

## Tasks
- [ ] **A1 薄膜** `thinfilm.js`: 特性行列法(s/p、多層、複素屈折率なし)。テスト: 膜なし = フレネル、MgF₂ λ/4 の理論値、ブリュースター角、R+T=1、λ/2 膜は無膜と同じ
- [ ] **A2 色** `color.js`: CIE 1931 等色関数(Wyman 2013 の解析近似)、XYZ→線形 sRGB、等エネルギー白 = 中性灰になる白色補正、sRGB ガンマ。テスト: 平坦スペクトル → 灰、単色の色相
- [ ] **A3 断面** `profile.js`: セグメント(直線・円弧・ベジェ・スプライン・非球面)の評価、弦誤差 0.1 µm での分割と厳密法線、閉合・自己交差・r ≥ 0 の検証、点の内外判定。テスト: 円弧のサグが球面式と一致、分割誤差、交差検出
- [ ] **A4 取り込み** `import-svg.js` `import-dxf.js` `import-csv.js`。テスト: 同じ平凸レンズを 3 形式で読み込み、サグ差 < 1 µm
- [ ] **A5 シーン** `scene.js`: レンズデータからコバ付き部品を自動生成(共有面)、部品の重なり検査、点の媒質判定。テスト: 生成した断面が閉じている/面の位置が一致/オイル層が隣と面共有
- [ ] **A6 非逐次追跡** `nstrace.js`: 円錐台との交点、BVH、最近交点、媒質の前後判定、界面イベント。テスト: 逐次追跡(`traceRay`)と同じ経路、全反射、共有面の 1 回処理
- [ ] **A7 描画** `render.js`: カメラ、環境プリセット、点・面光源、スペクトル分岐追跡、プログレッシブ蓄積、界面ごとの寄与。テスト: 受け入れ基準 1〜3(平板の反射 2R/(1+R)、屈折率整合面が不可視、MgF₂ の紫色)
- [ ] **A8 解析** `analysis.js`: 反射率の角度・波長グラフ用データ、線に沿った輝度断面、ウェーバーコントラスト、判定。テスト
- [ ] **A9 UI**: 「結像/外観」タブ、部品リスト、描画ビュー(ドラッグ回転、線の断面)、照明設定、角度一覧、断面エディタ(各ツール・グリッド・スナップ・寸法・undo/redo・下絵・数値表)、取り込みダイアログ、保存/読込
- [ ] **A10 受け入れ・セルフレビュー**: ブラウザで基準 1〜7、使い勝手、文字化け、性能。README 更新
